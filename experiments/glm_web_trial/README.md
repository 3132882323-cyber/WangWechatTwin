# 智谱网页隔离草稿网关（实验）

这是独立本机端口试验，未接微信发送、未加入正式模型路由。正式日常通道保持豆包，专业/激动情绪保持 GPT。不能仅修改生产 YAML 就把此实验替换进去。

网关固定监听 `127.0.0.1:19659`，所有接口要求本机 Bearer key。`user` 必须是当前联系人唯一的64位小写 SHA256；`request_id` 必须是唯一外部消息编号。模型别名为 `chatglm-web`，实际模型版本没有验证，响应标为 `web_assistant_unverified`，不能凭别名声称运行 GLM-5.3。

每个联系人保留同一远端对话编号。请求、会话归属及 pending/unknown 保存在 SQLite，重启不消除未知结果、不重提同编号、不自动新建替代会话。单并发，忙时领取前返回429；一次正常刷新和最多一次生成，没有代理/账号轮换或验证码绕过。

成功必须有真实上游 SSE `status=finish`、完整文字、对应对话编号及严格 ReplyDecision/A/B/C。`tool_calls` 字典只作为被动网页元数据，网关不执行、转发或保存其参数；这类草稿强制审核、置信度0。只有工具信息、截断、无效 JSON 或其他未支持格式保持未知。这个实验不证明网页平台内部工具完全关闭，因此不提升为自动发送通道。

## 账号与启动

只使用本人明确授权的必要智谱刷新令牌，放入本机 `auth/refresh.json`，结构字段为 `refresh_token` 和 `source=authorized_single_glm_tab`。不要读取整份浏览器资料、在聊天中贴令牌或提交账号文件。源码不自动采集浏览器凭据；此字段只是授权来源记录，不能替代用户许可。

在已安装本项目依赖的 Python 环境执行：

```text
python experiments/glm_web_trial/gateway.py
```

首次启动生成 `local-key.txt`，会话账本为 `state/gateway.sqlite3`。这些目录和文件已加入 gitignore；本项目不分发实际令牌、会话或浏览器配置。没有为此实验注册开机任务，也未验收24小时运行。

离线测试：

```text
python -m pytest tests/test_glm_web_trial.py -q
```

## 2026-10-12 实测边界

Windows本机两个虚构联系人各两轮，经本机端口全部返回严格三候选。各联系人两轮使用相同远端对话，不同联系人远端编号不同；本机提供的各自虚构记录记忆核对通过，约7.8/7.2/6.0/6.0秒。两轮带工具元数据，已强制审核。回忆依据是本机注入的虚构记录，不能据此声称网页纯历史记忆已独立验证。没有发送微信。

之前三轮格式失败留在私有试验账本，没有清理或重新提交。离线29项测试与真实网页短测分开报告。此结论不证明长期稳定、生产微信送达或免费无限使用。

普通千问匿名试验能列模型，但创建对话遇HTML验证页，已停止，没有执行其防机器人绕过代码。
