# 网页反代接口短测（2026-10-11）

在 Windows 本机独立试验目录验证 [FreeDeepseekAPI](https://github.com/ForgetMeAI/FreeDeepseekAPI/commit/648e708498bfae54cce085015fe5cf6e3e02b414)（MIT）与 [Doubao2API](https://github.com/2951461586/Doubao2API/commit/cc14a647f9dd4b769eb78b822bcb18e0387b7b45)（Apache-2.0）。用户明确授权本次新登录会话及最多6次虚构文字/静态图片请求。没有读取原浏览器或豆包桌面账号，没有发送微信测试消息或修改正式模型路由。

## 真实接口结果

| 服务 | 请求 | 端到端耗时 | 本轮检查 |
|---|---|---|---|
| DeepSeek 快速文字 | 虚构联系人 A 写入标记 | 1.297秒 | 返回正文 |
| DeepSeek 快速文字 | 虚构联系人 B 写入不同标记 | 1.078秒 | 返回正文、远端会话ID不同 |
| DeepSeek 快速文字 | A 回查 | 0.828秒 | 标记正确、复用A原远端会话 |
| DeepSeek 快速文字 | B 回查 | 0.750秒 | 标记正确、复用B原远端会话 |
| 豆包快速 | 虚构文字回应 | 3.516秒 | 返回非空正文 |
| 豆包视觉 | 合成PNG两种图形和数字 | 6.250秒 | 返回非空正文，颜色/形状/数字关键词检查通过 |

共6次请求、6次有效回复，自动重提为0。耗时是这些小输入和短输出的接口耗时，不是实际微信回复耗时，不能直接与带大量历史资料的网页业务任务比较。

图片判定采用“蓝、方、黄、圆、42”等关键词；没有保存完整生成正文做颜色与形状配对的人工复核，因此不将该检查扩展为全面视觉正确性。没有测试动态表情、多图、真实业务语气、专业回复、连续并发、重启后会话恢复、登录续期或24小时稳定性。DeepSeek的隔离/复用结论仅针对本次同一服务进程内的两个虚构联系人。

## 隔离措施与执行边界

- 独立回环服务端口、独立状态和密钥；禁止默认桌面凭据导入。
- DeepSeek要求明确且一致的会话键，限制单账号单并发，禁止账号切换、会话重提、空答修复和自动续写。
- 豆包缺少API密钥/管理密码时拒绝访问，禁止桌面/手工Cookie导入和额外生成技能；仅测试文字与data URL静态图。
- 登录由用户本人完成。DeepSeek只在独立新Chrome配置采集必要登录字段；豆包使用新二维码登录，不读取桌面配置。
- 豆包服务启动被执行器以“blocked by policy”拒绝，未用其他命令绕过；用户手动启动后核对进程归属，才开始接口试验。
- 试验结束已停止两个反代服务及独立登录调试浏览器，原浏览器和生产系统配置未改。新会话仅存本机隔离目录，未随源码公开。

## 可得结论

两个经限制的试验副本在本机均完成了真实生成，能作为接口式草稿通道的候选。本次样本不足以证明长期更稳定，更不能据此切换所有联系人自动发送。后续整合应增加持久联系人到会话映射、明确错误分类、未知结果不重提、业务草稿验收及发送前后守卫，再用持续运行数据判断稳定性。
