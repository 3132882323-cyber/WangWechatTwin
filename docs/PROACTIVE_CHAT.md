# 主动聊天建议

主动问候和话题跟进均只进入审核台。调度器没有发送接口；用户逐条批准后，正常发送管线才会调用已验证的本机 HTTP 文字接口。

在已有配置中增加：

```yaml
proactive:
  enabled: true
  review_only: true
  all_existing_contacts: true
  purpose: both
  min_idle_hours: 24
  cooldown_hours: 72
  max_drafts_per_day: 3
  active_start_hour: 10
  active_end_hour: 20
  interval_seconds: 300
```

时间窗口使用北京时间。仅考虑近 30 天内聊过的已有个人联系人，排除本人、群聊和系统账号。存在待审或已批准草稿、最后一条对方消息尚未回复、本人连续发出两条未获回复的消息时，不生成新的主动建议。

跟进建议仅引用同一联系人的低风险原话，历史计划不当作当前事实；没有合适话题时生成简短问候。当前版本采用本机模板生成主动建议，尚未通过网页模型进行个性化主动话题规划。

批准发送前再次核对当前聊天的新消息时间；生成后发生新的聊天则拒绝发送旧建议。冷却计时从生成草稿开始，拒绝草稿不会立即再生成。

Windows 本机已验证三条草稿生成和审核台显示；未对这些真实联系人执行主动发送测试。表情包图片发送接口仍在适配，当前版本只验证过识别与原始文件保存。
