# 本机语音试听

文字回复、语音合成和微信原生语音发送是三条不同的链路。当前微信发送接口支持文字及图片；本说明的命令只保存本机音频，不能把音频文件附件当作微信语音条。

## 豆包预设音色

`app.doubao_voice` 使用本人已授权的豆包 QR 会话产生单句预览。语音接口需要原会话中的 `sessionid_ss`；不能伪造登录字段或从其他浏览器批量采集凭据。网页服务的协议和可用性仍可能变化。

```text
python -m app.doubao_voice --help
```

命令需要一份私有会话文件、仅含已授权朗读文字的 UTF-8 文件、私有输出目录和唯一请求编号。必须有 ffmpeg 与 ffprobe；接收到的 AAC 先验证再转换成 MP3，再次验证后才发布。输入目前限一整句，服务返回的朗读文字须与完整输入一致。未完成、未知或已经完成的请求编号都不能重提。

这是豆包**预设音色**，不代表用户本人声线。真人声线需要单独的参考声音、来源核对和本机或另经授权的声线模型。不要把已有联系人发送的语音当作本人的参考，也不要把参考录音、会话文件、模型缓存或生成音频提交到仓库。

## 本人声线

本机参考声线可以研究官方 [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS) 的 Base 模型。其本机推理与豆包网页预设音色不同；首次需下载模型并安装独立依赖，不能直接升级已运行微信后台的 Python 环境。参考音频只应来自已核对、本人确认的录音，转写不确定时不能把它当作可信字稿。

音频生成成功不证明音色、口气或文本内容完全一致；先试听核对，再决定是否启用。应让 GPU 与系统内存不足时停止该条任务，避免阻塞微信文字回复。

本项目没有声纹身份验证，也不承诺克隆效果与真人完全相同。当前原生接口尚未验收语音发送，生成的本机试听不自动发给任何联系人。

协议参考：[豆包 TTS 连接实现](https://github.com/ljheee/tts-extension)。该仓库未提供许可证，本项目只参考协议行为，未复制其源码。
