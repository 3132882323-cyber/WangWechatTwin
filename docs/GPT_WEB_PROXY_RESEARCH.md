# GPT 网页转本地 API 候选（2026-10-11，只读研究）

本轮只核对公开 GitHub 仓库的许可证、源码、维护时间和依赖。没有读取本机 ChatGPT Cookie、Access Token 或会话文件，没有安装、启动或调用任何 GPT 网页反代。以下候选均**未接入本项目，也未在本机实测 GPT 生成**。OpenAI [API 模型目录](https://developers.openai.com/api/docs/models)列有 GPT-6 Astra 等模型 ID，但官方 API 的模型 ID 不能证明第三方项目已正确连接 ChatGPT 网页中的 GPT-6 或 Pro 档。

|---|---|---|---|
| [lanqian528/chat2api](https://github.com/lanqian528/chat2api)，[MIT](https://github.com/lanqian528/chat2api/blob/main/LICENSE) | main 最近提交为 [2025-03-28](https://github.com/lanqian528/chat2api/commit/a63a90cec90dea3fea3e272d22f8c5799de14e30)，dev 为 [2025-05-17](https://github.com/lanqian528/chat2api/commit/85971f04d101502bb064ed6d34c19303963026fc)。Docker 使用 Python 3.11；[依赖](https://github.com/lanqian528/chat2api/blob/main/requirements.txt)包括 FastAPI、curl_cffi、APScheduler。 | 支持 Access Token / Refresh Token 与定时续期，但[源码把令牌原文写入日志](https://github.com/lanqian528/chat2api/blob/85971f04d101502bb064ed6d34c19303963026fc/chatgpt/refreshToken.py#L14-L65)。遇到 Arkose 要求时，[未配置外部解题服务会返回 403](https://github.com/lanqian528/chat2api/blob/85971f04d101502bb064ed6d34c19303963026fc/chatgpt/ChatService.py#L221-L245)；Turnstile 可配置外部 solver。 | [dev 模型映射](https://github.com/lanqian528/chat2api/blob/85971f04d101502bb064ed6d34c19303963026fc/chatgpt/ChatService.py#L135-L181)只识别到 O3-mini 等旧档，未知名称回退 `gpt-4o`。没有 GPT-6 路由证明，且令牌日志、自动轮换与重试不适合直接复用。 |

旧项目 [acheong08/ChatGPT-to-API](https://github.com/acheong08/ChatGPT-to-API) 已归档，最近提交在 [2023 年](https://github.com/acheong08/ChatGPT-to-API/commit/1df9d25da870fdd5787cce874ac1f6284006672b)，不作为当前候选。

若以后评估 GPT 网页反代，应先用独立登录态和回环监听，只产生虚构内容草稿；实测返回的模型身份、联系人会话隔离、图片上传、登录续期和挑战处理。超时或提交结果未知时不自动重试；`/health` 只证明进程可达，不能代表模型生成成功。任何令牌、Cookie、二维码和真实聊天正文不得写入公开仓库或诊断日志。现阶段 GPT 仍使用原网页通道，本研究没有改变生产路由。
