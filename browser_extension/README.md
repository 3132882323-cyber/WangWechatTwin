# 网页连接（实验功能）

普通 ChatGPT Chat 临时会话，不使用 Work/Codex CLI。最多维护 3 个由本扩展创建的专用标签页；同一联系人复用同一临时对话。切换联系人、会话失败或达到 24 轮时，在原标签页重置，不把不同联系人的对话混用。核验“不个性化”和 GPT-5.6 Instant；读取失败、页面改变或限额时停止，不回退到 Codex。20× 套餐不是所有模型无限调用的保证。

配置 `openai.provider: web`，`web.port: 18769`。安装本目录扩展后，在扩展配置页填入本机 `.runtime/browser_bridge/pairing_token.txt`。配对码不得上传 GitHub。扩展只访问 `https://chatgpt.com/*` 和 `http://127.0.0.1:18769/*`；不读取原有网页聊天。

更新源代码后需在 Chrome 扩展管理页重新加载一次，保留原配对码。池记录使用浏览器会话存储，工作线程重启可以继续复用；完整重启浏览器后不会盲目认领已有用户标签页。手动改动专用页的对话或输入时停止处理，不清空用户编辑。每次只接收新消息编号的回答，避免将上一轮答案误认为本轮回复。

纯分配策略测试：`node --test browser_extension/pool.test.cjs`。本机连续请求验证应检查同一标签页、相同对话指纹、第二轮新回答及不同联系人隔离；源码测试不能替代浏览器运行验证。

快速连接使用认证的本机 WebSocket 就绪通知，30 秒 alarm 只作断线恢复兜底。复用会话时沿用已核验的 Instant 选择；普通问候减少无关历史输入。协议只通知有任务，不传聊天正文或在 URL 中放配对码。Chrome 最低要求 116，生命周期依据 [Chrome 官方 WebSocket 文档](https://developer.chrome.com/docs/extensions/how-to/web-platform/websockets)。真实回复速度受模型、网络、截图上传和微信窗口状态影响，首次打开会话比复用慢。

固定对话复用已完成本机 Chrome 实测：同一模拟联系人连续两轮使用同一标签页和相同对话指纹，第二轮从该对话取回第一轮测试词；另一位联系人使用独立对话；第 4 位联系人在第 1 个标签页重置为新对话，窗口总数仍为 3。验证没有发送微信消息。另有 5 项纯分配策略测试及 45 项 Python 检查；这些记录不代表所有浏览器版本或长期运行均已验证。

当前验证状态：本机 Windows 上，扩展自动建立不个性化临时会话并生成结构化合成草稿已成功；一条本人实际发出的历史语音已经通过微信内置转文字，并核验消息身份。不是所有语音、微信版本或长期运行场景都已验证。历史检索按联系人隔离，重大信息仍留审核。语音、网页 UI 或联系人核验失败时停止处理并保留草稿，不猜内容，不把源码测试当作收发成功。


## 三路网页连接

- DeepSeek：日常文字、语音转写后的回复；一个专用页，关闭搜索与深度思考。
- 豆包：图片、表情包识别；一个专用页，按联系人保存各自对话，使用备注命名。
- GPT：专业问题与明显激动情绪；原有临时对话窗口池与最高思考档。

扩展只在自建的专用对话中处理本机端口派发的必要资料，不读取已有个人网页聊天。新增豆包网站权限及上下文传输需要用户明确授权。网页连接不等于官方 API；正式运行不依赖 Codex 浏览器控制。保留本机配对码，更新源代码后重载扩展。
