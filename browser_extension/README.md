# 网页连接（实验功能）

普通 ChatGPT Chat 临时会话，不使用 Work/Codex CLI。每个任务新建临时会话并核验“不个性化”和 GPT-5.6 Instant；读取失败、页面改变或限额时停止，不回退到 Codex。20× 套餐不是所有模型无限调用的保证。

配置 `openai.provider: web`，`web.port: 18769`。安装本目录扩展后，在扩展配置页填入本机 `.runtime/browser_bridge/pairing_token.txt`。配对码不得上传 GitHub。扩展只访问 `https://chatgpt.com/*` 和 `http://127.0.0.1:18769/*`；不读取原有网页聊天。

当前验证状态：本机 Windows 上，扩展自动建立不个性化临时会话并生成结构化合成草稿已成功；一条本人实际发出的历史语音已经通过微信内置转文字，并核验消息身份。不是所有语音、微信版本或长期运行场景都已验证。历史检索按联系人隔离，重大信息仍留审核。语音、网页 UI 或联系人核验失败时停止处理并保留草稿，不猜内容，不把源码测试当作收发成功。
