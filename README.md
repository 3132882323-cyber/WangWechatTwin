# 微信聊天记忆分身

一个在 **Windows 本机运行**的微信回复助手：先读懂这段对话是谁在说、说过什么，再参考本人给这位联系人的实际表达，生成草稿或在授权范围内回复。

它关注的是个人聊天记忆和交流习惯，不预设用户是老板，也不把某个联系人或旧项目中的人物当成本人。仓库地址中的 `WangWechatTwin` 是历史工程名称，**不代表用户身份**。

## 怎样理解一段聊天

- 区分本人、当前联系人和引用中的第三人。别人说的“我”，不自动变成本人的经历。
- 按联系人保存日期、说话人和原文依据。检索相关话题时带回前后交流，不只抽一句话。
- 优先学习本人亲手修改的回复，再参考相似情境原话、当前联系人习惯和全局表达统计。
- 旧报价、计划、情绪和承诺不是今天的事实。没有本人立场依据时，不替本人编理由、作决定。
- 不把另一个联系人的私聊原文混入当前对话，不宣称复制了完整人格。

| 功能 | 状态 |
|---|---|

| 本机 HTTP 原生发送，无 GUI 发送回退 | 微信 4.1.15.13 已通过真实新消息 → 网页生成 → HTTP 自动回复及服务器确认验收；一次实测约 6.95 秒 |

| 本机离线语音转文字 | 按联系人和消息编号提取 SILK，后台 Whisper 转写；一条本人真实语音与先前微信转写核对一致，并通过网页草稿验收 |
| 固定最多 3 个网页窗口，同一联系人复用对话 | 已完成连续复用及容量实测 |
| 表情包文件校验、静图/动图抽帧、网页视觉理解 | 已从真实记录取图并验证文字与语义识别；动图、多图及失败场景仍有边界 |
| 主动问候与话题跟进 | 本机已生成并显示 3 条审核草稿；默认关闭，启用后仍须逐条批准；间隔、每日上限与未回复检查已接入 |
| 表情图片接口发送与审核建议 | 原图通过本机 HTTP 发送，已核验新的本人图片消息、同图 MD5 与服务器确认；建议先审核。微信原生收藏表情类型 47 尚未完成接口验收 |
| 普通图片识别 | 本机 V2 图片解码、长截图清晰裁剪、网页视觉草稿已验收；回复先审核 |
| 文件、视频及其他未解析内容 | 留审核，不假装看懂 |

普通网页连接使用“不个性化临时聊天”，只输入微信任务所需上下文，不读取已有网页对话。API 和 Codex 账号连接仍可选；不同产品额度有各自边界，不保证无限使用。连接失败不会偷偷回退到 Codex。

自动发送默认关闭。日常低风险回复须明确开启；钱款、合同、账户、责任及缺乏事实依据的承诺留审核。发送前核验账号和联系人，发送后读取新的本人消息及服务器编号；这不等于联系人已读。图片识别或窗口状态不明确时停止该条处理。

## 安装

环境：Windows 10/11、Python 3.10–3.12。微信 GUI 兼容目前严格校验 `4.1.15.13`，其他版本不能据此保证可用。

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m pip install wxauto4==41.1.7
```

确认没有已有配置后，再从 `config.example.yaml` 与 `.env.example` 创建自己的配置。**不要覆盖已有密钥、配置或数据库。**双击 `START_HERE.bat` 可进入本机菜单。

仅连接本人有权访问的已登录微信账号：

```powershell
.venv\Scripts\python.exe scripts\connect_local_history.py --db-dir "<本人账号db_storage绝对路径>" --i-own-this-account
.venv\Scripts\python.exe -m app --config config.history.yaml run --mode shadow
```

先完成只读、草稿、明确测试联系人与内容的发送验证，再按需要开启 `low_risk_auto`。群聊单独授权，默认只处理 @ 本人的消息。公众号和系统通知不自动回复。

网页模型连接见 [扩展说明](browser_extension/README.md)，角色与人物记忆见 [角色画像说明](ROLE_PROFILE.md)，本机 HTTP 接口的条件与未完成项见 [接口连接说明](docs/LOCAL_HTTP_TRANSPORT.md)。本机审核台由配置中的 `web.port` 决定，只应监听本机。

主动聊天见 [审核规则](docs/PROACTIVE_CHAT.md)，表情图片库与接口见 [表情图片说明](docs/STICKER_IMAGES.md)。

语音、图片和表情的识别安装及验收边界见 [媒体识别说明](docs/MEDIA_RECOGNITION.md)。

## 双网页模型与个人记忆

`openai.provider: hybrid_web` 将日常低风险文字交给 DeepSeek 快速模式；复杂问题和图片交给 GPT 网页最高思考档。DeepSeek 深度思考、智能搜索均关闭。两条通道共享本机审核与发送规则，每条任务只选择一个模型。网页账户登录和扩展配对需本人授权。

独立个人数据库保存双方交流，并区分 AI 发送、自动听写、本人纠正与来源不明确的历史内容。新消息读取与模型生成分离，发送前核对本人新发言及更晚入站消息，阻止过时回复。审核台支持纠正原文后重新起草。

Windows 登录启动可通过当前用户 Startup 快捷方式，依次启动选定 VPN、微信、已配对浏览器和后台；复用已有进程，避免两个 VPN 同时启动。启动 VPN 应用不等于自动连接，实际重启须单独验收。

DeepSeek 专用对话按微信联系人备注命名，最多同时保留 10 个窗口；超出后保存对话地址并按最近使用时间回收窗口。联系人识别仍使用独立会话标识，重名或修改备注不会合并聊天。群聊遵循仅处理 @ 本人的配置。
